=====================================================================
  MAARAA BILL MANAGER - STEP-BY-STEP SETUP
=====================================================================

Time needed : about 15 minutes
You need    : a computer (Chrome recommended), the MAARAA owner Google
              account, and this zip file unpacked.

The zip contains one folder:
  1-Main-Bill-Manager   -> goes into the Google Sheet (13 files)

Staff do NOT need a Google account. Each person picks their name
from a list and types the team PIN  2018  (they can change it to a
private PIN afterwards).

Your current team is added automatically by setup (alphabetical):
  Asindu, Asvida, Avera, Bhagya, Binudi, Duvindu, Isirie, Kaushan,
  Oshini, Savidya, Senura, Tharangika, Uditha
People come and go: add or remove them any time in the Users
screen (Part 6). Nothing else needs to change.

TIP: Open each file in Notepad, press Ctrl+A then Ctrl+C to copy all,
     then Ctrl+A then Ctrl+V in Apps Script to replace everything.

Tick each box [ ] as you go.

ALREADY INSTALLED AN EARLIER VERSION?  Skip to "UPGRADING" near the end.


---------------------------------------------------------------------
PART 0 - SIGN IN WITH THE OWNER GOOGLE ACCOUNT (owner only)
---------------------------------------------------------------------
[ ] 0.1  Open Chrome and go to:  https://accounts.google.com
[ ] 0.2  Sign in with the MAARAA OWNER Google account
         (the account that should own all bills, receipts and backups).
[ ] 0.3  If you are signed in to several Google accounts, sign out of
         the others (or use a separate Chrome profile). Apps Script
         works best with only ONE account signed in.


---------------------------------------------------------------------
PART 1 - CREATE THE SPREADSHEET
---------------------------------------------------------------------
[ ] 1.1  Go to:  https://sheets.new   (creates a blank Google Sheet)
[ ] 1.2  Rename it (top left):   MAARAA Bills
[ ] 1.3  Menu:  Extensions > Apps Script.  A new tab opens.
[ ] 1.4  Rename "Untitled project" to:   MAARAA Bill Manager


---------------------------------------------------------------------
PART 2 - PASTE THE FILES  (folder: 1-Main-Bill-Manager)
---------------------------------------------------------------------
How to add a file in Apps Script:
   Click  +  next to "Files"  >  "Script" or "HTML"  > type the name
   WITHOUT the extension (type  Api  not  Api.gs) > Enter > delete the
   sample text > paste the file contents.

[ ] 2.1  Code.gs already exists: open it, select all, delete, and
         paste  Code.gs  from the zip.
[ ] 2.2  Add these SCRIPT files (+ > Script):
            Api          <- Api.gs
            Users        <- Users.gs
            Backup       <- Backup.gs
            Integrity    <- Integrity.gs
            Reports      <- Reports.gs
[ ] 2.3  Add these HTML files (+ > HTML):
            Index            <- Index.html
            Styles           <- Styles.html
            Common           <- Common.html
            CategoryManager  <- CategoryManager.html
            UserManager      <- UserManager.html
            Sidebar          <- Sidebar.html
         Names are case-sensitive ("Index", not "index").
[ ] 2.4  Settings file:
         - Gear icon "Project Settings" > tick
           "Show "appsscript.json" manifest file in editor".
         - Back in the Editor, open  appsscript.json, select all and
           paste  appsscript.json  from the zip.
         - In Project Settings, check that Time zone is
           "(GMT+05:30) Colombo".
[ ] 2.5  Press Ctrl+S. You should see 12 files plus appsscript.json,
         and no red error lines.


---------------------------------------------------------------------
PART 3 - RUN SETUP
---------------------------------------------------------------------
[ ] 3.1  Open  Code.gs. In the toolbar function list (next to
         "Debug"), choose  setup  and click  Run.
[ ] 3.2  Permission window (owner only, one time):
         "Review permissions" > choose the owner account >
         "Google hasn't verified this app" > Advanced >
         "Go to MAARAA Bill Manager (unsafe)" > Allow.
         (This is normal for your own script. Staff never see it.)
[ ] 3.3  Go back to the SPREADSHEET tab. A message box shows
           "Setup complete"  and  YOUR LOGIN + PIN for the app.
         >>> WRITE DOWN YOUR PIN. <<<
         As an Admin you get your OWN random PIN, never the team PIN,
         so nobody can sign in as you with 2018.
         (If the box doesn't appear, reload the spreadsheet with F5
          and run setup from the menu: Bill Manager > Setup / repair.)
[ ] 3.4  Reload the spreadsheet (F5). Check that:
           - the tabs Bills, Monthly Summary, Annual Summary,
             Categories, Payment Methods, Audit Log, Settings and
             Users exist
           - the "Bill Manager" menu appears next to Help
           - Google Drive has a folder "MAARAA Bill Manager"


---------------------------------------------------------------------
PART 4 - PUBLISH THE APP (one link for everyone)
---------------------------------------------------------------------
[ ] 4.1  In Apps Script: blue  Deploy  button > New deployment.
[ ] 4.2  Gear next to "Select type" > Web app.
[ ] 4.3  Fill in:
            Description     : MAARAA Bills
            Execute as      : Me (your owner e-mail)
            Who has access  : Anyone
[ ] 4.4  Click Deploy (Allow again if asked).
[ ] 4.5  COPY the "Web app URL" (ends with /exec). This is the
         ENTRY LINK you send to staff. Save it in Notepad.
         Later you can see it again in:
         Bill Manager > Show the entry link for staff.


---------------------------------------------------------------------
PART 5 - TRY IT YOURSELF
---------------------------------------------------------------------
[ ] 5.1  Open the ENTRY LINK on your phone or in a new browser tab.
[ ] 5.2  Choose "Owner" in the name list (or "Other" and type your
         login) and enter the PIN from step 3.3. Tip: in Users > Edit,
         change the name "Owner" to your own name.
         Keep "Keep me signed in on this device" ticked.
[ ] 5.3  Record a test bill with a photo. You should see "Recorded."
         with a number like BILL-202611-0001 and a green
         "Verified" line.
[ ] 5.4  Optional: to change your PIN, open the people icon (Users)
         and press "New PIN" on your own row.


---------------------------------------------------------------------
PART 6 - YOUR TEAM (changes from time to time)
---------------------------------------------------------------------
Open the Users screen: the people icon at the top of the app, or in
the spreadsheet Bill Manager > Manage users. Everyone is listed in
alphabetical order.

[ ] 6.1  Check the list: the 13 current employees are there with the
         team PIN 2018.
[ ] 6.2  Someone NEW joins:
            - one person: fill in Login (e.g. nadun), Name, Role >
              "Add account" (leave PIN empty = team PIN 2018)
            - several people: "Add several people at once" > type the
              names separated by commas > "Add people"
[ ] 6.3  Someone LEAVES or is on long leave:
            - "Switch off": blocks sign-in at once and keeps their
              history (recommended)
            - or "Delete": removes them; their past bills keep their
              name
[ ] 6.4  Forgotten PIN: "Reset PIN" sets it back to the team PIN 2018
         (Admins get a new random PIN instead).
[ ] 6.5  Someone should manage categories and users too: Edit > Role
         = Admin. They automatically get a private PIN, shown once.
[ ] 6.6  To change the team PIN for NEW people: Settings tab >
         DEFAULT_PIN. People who already have 2018 keep it until they
         change it or you press Reset PIN.

---------------------------------------------------------------------
PART 8 - TEST BEFORE REAL USE  (10 minutes)
---------------------------------------------------------------------
[ ] 8.1  One employee signs in and records a test bill. In the sheet,
         "Recorded By" shows their login and name.
[ ] 8.2  Check that the employee does NOT see the people or category
         icons, and does not have the spreadsheet.
[ ] 8.3  The employee opens "My bills" > Edit, changes the amount and
         saves. The row in "Bills" updates, and "Last Edited By"
         shows them.
[ ] 8.4  Switch that employee off in Users. Their app now asks them to
         sign in again, and the sign-in is refused. Switch them back on.
[ ] 8.5  Bill Manager > Run integrity check. It should say "Errors: 0".
[ ] 8.6  Bill Manager > Backup & restore > Back up now.
[ ] 8.7  Void the test bills: click a test row in "Bills" > Bill Manager
         > Void selected bill > reason "Test".
[ ] 8.8  Optional: in the "Settings" tab, put your e-mail in
         ALERT_EMAIL to be warned if a nightly backup fails.


---------------------------------------------------------------------
DAILY USE FOR THE ADMIN
---------------------------------------------------------------------
Monthly Summary tab
   Pick the Month (C3) and Year (D3) from the dropdowns. The page
   redraws in a few seconds and shows the totals, budget against
   actual by category, payment methods, who recorded what, and every
   bill of that month.
Annual Summary tab
   Pick the Year (C3). It shows every category for Jan-Dec, with
   group subtotals and the grand total.
Print / PDF (A4)
   Bill Manager > Save Monthly Summary as PDF (A4) or Save Annual
   Summary as PDF (A4 landscape). The PDF is saved in
   Drive > MAARAA Bill Manager > Reports.
Correcting a bill in the sheet (Admin)
   In the Bills tab, edit the white-header columns directly. The
   grey-header columns are locked and filled in automatically.
   Total is recalculated and the change is logged.
Employees correcting their own bills
   In the app: My bills > Edit > Save changes. They can only change
   their own bills, for 30 days (EDIT_WINDOW_DAYS in Settings).
Summaries refresh automatically every 5 minutes, and whenever a
dropdown changes. Bill Manager > Refresh summaries forces it.


---------------------------------------------------------------------
UPGRADING AN EXISTING INSTALLATION
---------------------------------------------------------------------
Your bills, receipts and users are kept. Only the code changes.

[ ] U.1  Open the spreadsheet > Extensions > Apps Script.
[ ] U.2  Replace the contents of ALL these files with the new versions
         from 1-Main-Bill-Manager:
            Code, Api, Users, Backup, Integrity, Reports,
            Index, Styles, Common, UserManager
         (If you don't have "Reports" yet: + > Script > Reports.)
[ ] U.3  Save (Ctrl+S). Choose "setup" in the function list > Run.
         Read the message in the spreadsheet tab. It shows YOUR LOGIN
         and PIN. Write the PIN down.
         Setup also repairs the Users and Categories tabs, applies the
         layout, locks the system columns and redraws the summaries.
[ ] U.4  Deploy > Manage deployments > pencil (Edit). Check that
         "Execute as" is "Me" and "Who has access" is "Anyone", choose
         Version: New version > Deploy.
         >>> From now on, THIS link is the entry link for everyone. <<<
         (Bill Manager > Show the entry link for staff shows it.)
[ ] U.5  Setup adds the 13 current employees with PIN 2018 if no
         employees are listed yet. Open the people icon (Users) and
         check the list. Anyone added earlier keeps their name and
         role. Press "Set PIN" on them to give them the team PIN, or
         Delete them if they are listed twice. Then send everyone the
         entry link (Part 7).
[ ] U.6  The old "MAARAA Bills Entry" project (the Google sign-in
         link) is no longer needed. You can delete it at
         https://script.google.com. Its link now only says
         "This entry link has been replaced".
[ ] U.7  Open "Monthly Summary", pick a month, and check the totals.
         If setup said "Setup finished with problems", or a summary
         shows "This summary could not be drawn", send a screenshot.


---------------------------------------------------------------------
IF YOU CHANGE THE CODE LATER  (important)
---------------------------------------------------------------------
Saving the code alone does NOT update the live link. After pasting
new code:
   Deploy > Manage deployments > pencil (Edit)
   > Version: "New version" > Deploy.
The link stays the same, so you don't need to send it again.


---------------------------------------------------------------------
TROUBLESHOOTING
---------------------------------------------------------------------
My name is not in the list on the sign-in screen
   -> The admin adds you (Part 6.2), or switches you back on.

"Login or PIN is not correct"
   -> Check the login spelling (it is in the Users screen), or give
      them a New PIN.

"This login is locked for 15 minutes"
   -> 5 wrong PINs. Wait 15 minutes, or give them a New PIN and wait.

"No PIN has been set for this login yet"
   -> Users > Set PIN.

"Your sign-in has ended / Your PIN was changed"
   -> Normal after a New PIN or Switch off. Sign in again.

Staff see "This entry link has been replaced"
   -> They are using the old link. Send them the new link (U.4).

The app shows "Sign in" every time
   -> Tick "Keep me signed in on this device", and don't use private
      or incognito browsing.

The "Bill Manager" menu is missing
   -> Reload the spreadsheet (F5). If it is still missing, run setup
      again (Part 3).

A row was deleted by mistake
   -> Bill Manager > Backup & restore > Rebuild Bills from live journal.
